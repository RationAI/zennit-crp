CRP composite gallery

For each concept detector, the images that most excite it plus their conditional CRP heatmaps — so you can see what a detector responds to and where. Pick a model, an instance (LRP composite × concept basis), a layer, an image sample (a fixed input, or the dataset aggregate), and a reference ranking. Only computed combinations are listed.

Concept basis: attention heads — one concept per head; or axis-aligned — one concept per embedding dimension (standard CRP). The composite (CP-LRP or Chefer) sets the relevance rule; the heuristic-optimal instances instead show the detectors an occlusion search ranked most important. Relevance is signed by default (negatives kept); a positive-only instance is the opt-in exception.

Each detector figure has three sub-rows: image (reference or query), relevance (its conditional CRP heatmap), and RF crop — the image clipped to the heatmap's high-relevance region, showing where the concept latches on. The aggregate sample shows the top dataset images for a detector; a named sample shows that one input's locally most-relevant detectors.

Reference ranking orders the shown images by how the detector scores them: rel (attributed relevance) or act (raw activation), each reduced over tokens by sum or max — i.e. relsum / relmax / actsum / actmax.

Heatmaps are class-conditional (CRP): relevance is initialised at the predicted/true class, masked at the concept, and propagated to the input (θ = {L:class, l:concept}).
