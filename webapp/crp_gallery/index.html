CRP composite gallery

Saliency maps + representative images per LRP/CRP composite. Pick a model, an experiment instance (composite × concept basis — SAE or axis-aligned), an image sample (or the dataset aggregate), and a layer. Only computed combinations are listed.

Each detector figure has three sub-rows: image (reference or query), relevance (its conditional CRP heatmap), and RF crop — the image clipped to the heatmap's high-relevance region with low-relevance pixels faded, showing which part of the image the concept latches onto.

FV index picks how the reference index was conditioned: original = stock CRP, every dataset image attributed on its ground-truth label; condition-class-aligned = every image attributed on its top-3 predicted classes with p > 10% (one pass per class), references stored per conditioning class and served only when the explanation conditions on the same class.

Heatmaps are class-conditional, per the CRP paper: relevance is initialised at the output on the sample's true class, masked at the concept, and propagated to the input (condition set θ = {L:class, l:concept}). This differs from FeatureVisualization.get_max_reference, which starts the backward pass at the layer seeded with the layer activation and drops the class condition — that made the displayed heatmap inconsistent with the relevance used to rank the reference samples.
